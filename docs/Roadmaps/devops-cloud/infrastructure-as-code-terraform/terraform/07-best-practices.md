# Terraform Best Practices

Use this page for the conventions that tie the earlier topics together.

## Suggested sections

- Format and validate configurations in CI.
- Pin provider and module versions.
- Review plans through pull requests.
- Separate environments and state where appropriate.
- Protect credentials and sensitive state.
- Add policy checks and drift detection as the project grows.
