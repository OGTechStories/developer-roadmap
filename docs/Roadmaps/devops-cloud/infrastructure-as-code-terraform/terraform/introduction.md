# Terraform Fundamentals

Terraform is an open-source tool for provisioning and changing infrastructure through declarative configuration. You describe the desired result, and Terraform determines the changes required to reach it.

## Suggested order

1. Install Terraform and prepare a local environment or use any sandbox.
2. Learn the `init`, `plan`, `apply`, and `destroy` workflow.
3. Define providers and resources.
4. Add variables, outputs, and reusable modules.
5. Understand state and team workflows.
